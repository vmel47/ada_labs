# Study 003: standalone ADA Labs and verbose-output capture

This study evaluates a single reusable ADA README instruction: retain complete verbose command stdout/stderr before conversational display, then show a concise receipt while preserving diagnostics and independent access. It does not change production ADA or weaken mandatory verification.

## Matched experiment

The actual application is Repair Queue v1: Python standard library, SQLite, HTML/CSS/vanilla JavaScript, using the supplied handle_request adapter. Stable and candidate applications are independently developed from clean starters with the same explicit subscription runtime/model/effort, task and evaluation procedures. Neither previous pilot application is reused. The controller preserves actual phase receipts, failed tool events, corrections, native checks and screenshots.

The accepted ADA source originates in trial-0038f1aff9154d17. Its real prospective plan/design, implementation and independent source/behavior review consumed 919,859 measured logical input-plus-output tokens. Those one-time costs remain in the original history. Only the unchanged ADA artifact and its provenance are transferred, followed by a fresh independent compatibility review. No previous application, application plan, score or resource result is imported. The new task/suite identity differs only in the browser-action interpreter and validator; the exact compatibility manifest rejects changes to task/starter/mandatory criteria/evaluator/dependencies and all other procedures.

## Measurement limits

Logical token totals are actual CLI input plus output events, with cached input reported separately as a subset. Application totals include Lead and independent Reviewer; role costs and corrections are separated. They are not purchased-credit cost, subscription quota percentages, inference-only time or provider request counts. Supervising development/reviewer chat tokens, money, peak memory/CPU and exact per-edit self-check cycles remain unknown. Prior failed/incomplete CLI attempts are reported separately, including unknown consumption; they are not subtracted from the cost of building the Lab.

One stable-first pair is provisional. Public tests, stochastic development, different fresh sessions and unequal diagnostic work limit causal inference. A passing or cheaper candidate is not a confirmed Champion. Production ADA is unchanged and no promotion occurs.
