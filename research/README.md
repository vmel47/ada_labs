# First current-session pilot

The laboratory completed one real stable/candidate pair on Repair Queue. Both applications passed all ten mandatory backend/browser criteria and independent design, behavior and exact-source review. The stable application required one independently observed correction cycle for route/ID handling; the candidate required none.

**Outcome: no demonstrated advantage.** This single stable-first run shares the same lead context and known public tests. Fewer observed corrections do not establish a reliable architectural improvement. Provider tokens, model calls, session totals and monetary cost were unavailable and remain null. Deterministic evaluator time is not application development time.

The candidate adds a project-independent executable-contract preparation step to ADA's existing criteria stage. Its real project-specific suite was written before implementation, independently criticized, observed to fail on the missing implementation, then executed unchanged after implementation: six tests passed. The initial import failure proves ordering/absence only; it does not itself prove assertion quality.
